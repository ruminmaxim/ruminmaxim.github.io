Antivirus App

About the project

A comprehensive desktop application that combines many tools and utilities in one product: antivirus scanning, registry cleanup, vulnerability checks, tamper protection, startup management, and more. The main challenge was bringing many related utilities into a single interface. Special attention went to the scan and auto-fix screen, the core tool of the product. Issues were grouped into subcategories, and each group could be expanded to inspect individual vulnerabilities. I also prepared icons for every vulnerability type and group. We used interactive prototypes throughout the project. With this many connected features, prototypes helped us test links between screens and keep the overall logic coherent. A UI kit was prepared as well. The interface was assembled with an atomic approach, using MS Windows libraries as a base and customizing them where the product needed it.
