# Портфолио Рюмина Максима

Статический сайт на [Eleventy](https://www.11ty.dev/). После сборки он состоит из обычных HTML, CSS и JavaScript и публикуется на GitHub Pages.

## Локальный запуск

```bash
npm install
npm run dev
```

Eleventy запустит локальный сервер и будет пересобирать сайт после изменений.

## Проверка и production-сборка

```bash
npm run build
npm run check
```

Готовый сайт появляется в `_site/`. Команда `check` проверяет HTML, локальные ссылки, ресурсы, языки страниц и отсутствие Яндекс Метрики.

При push в `main` GitHub Actions выполняет эти же команды и публикует `_site/` на GitHub Pages.

## Где что находится

- `src/pages/` — английская и русская главные страницы.
- `src/cases/` — отдельные EN/RU-файлы кейсов.
- `src/_includes/layouts/` — общая оболочка главной и кейсов.
- `src/_includes/components/` — навигация, карточки проектов, контакты и футер.
- `src/_data/site.js` — контакты и общие подписи интерфейса.
- `src/_data/projects.js` — порядок карточек, обложки, названия и URL проектов.
- `src/assets/css/` — стили, разделённые по назначению.
- `src/assets/js/site.js` — меню, контакты и тултипы.
- `public/projects/` — изображения и видео кейсов.
- `public/` — шрифты, резюме и остальные статические файлы.

## Как добавить кейс

1. Скопировать похожий файл в `src/cases/`.
2. Изменить в front matter поля `title`, `lang`, `permalink` и `backHref`.
3. Добавить изображения в отдельную папку внутри `public/projects/`.
4. Один раз добавить обе локализации карточки в `src/_data/projects.js`.
5. Выполнить `npm run build && npm run check`.

Публичные имена существующих HTML-файлов сохранены специально, чтобы старые ссылки и закладки продолжили работать.
